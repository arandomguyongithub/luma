Luma, a powerful, fast and strong programming language based in Lua which was made to help new coders begin their journey and create more simplicity in the coding industry!
This is also inspired by luau (the Roblox coding language). It's like luau but for your real computer!. Or think of it as lua but with way more stuff.

# HOW TO INSTALL
1. Extract the zip file **into your user directory**
2. Run the `install.bat` file as administrator.
3. Read what it says carefully and press any key to continue.
4. Success! You have installed luma. You can close that terminal/command prompt window now!

# HOW DO I RUN MY CODE
To start using Luma, you must create a .luma file and you can open it with visual studio code, notepad or click "Edit with Luma editor" and from there, you can start writing luma code!
Then, when you have finished writing your code, simply run it by opening the file!
